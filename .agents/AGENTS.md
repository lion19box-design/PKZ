# Asset Naming Rules

When adding or formatting new viewer assets (e.g. in `public/assets/viewers`), they must conform to the following standard:

1. **Format**: `firstname-lastname-profession-city.ext`
2. **Casing**: All lowercase, words separated by hyphens.
3. **Uniqueness**: Cities should not repeat.
4. **Names and Regions**: Use realistic and culturally appropriate names depending on the city/region. Viewers write from all over the former Soviet Union. If a viewer is from Kiev, Yerevan, Ordzhonikidze, Almaty, etc., you should mix in local regional names and surnames (e.g., Armenian, Ukrainian, Kazakh names), while still occasionally using common Russian names, based on realistic demographic representation. Avoid overusing stereotypical "stock" names (like Ivan Petrov or Olga Ivanova).
