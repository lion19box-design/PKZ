# Что? Где? Когда? — Collector's Vault (Галерея оригиналов)

В этом каталоге бережно сохранены оригинальные материалы игры в максимальном студийном разрешении (1792×2392):

- **`viewers/`**: 60 оригинальных высокодетализированных портретов телезрителей со всего постсоветского пространства.
- **`viewers/blackbox/`**: 6 уникальных портретов телезрителей для раундов с черным ящиком.
- **`early-concepts/`**: Ранние концепты, черновые наработки и исторические варианты персонажей ранних итераций.
- **`avatars/`**: оригиналы аватаров знатоков в полном разрешении. В `public/assets/avatars/` лежат копии, уменьшенные до 480 px (имена файлов совпадают, их хранит база данных).
- **`screenshots-<версия>/`**: исходные скриншоты интерфейса без подписи версии. Подписанные копии для сайта — в `public/assets/screenshots/`.

### Назначение директории
Данный каталог находится вне рабочей директории `public/`. Сборщик Vite не включает его в итоговый бандл приложения (`dist`), благодаря чему эти драгоценные мастер-материалы хранятся в репозитории вечно и не расходуют квоту хостинга (Vercel Deployment Storage).
