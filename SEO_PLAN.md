# План SEO-продвижения «Почему? Куда? Зачем?»

Основной домен: `https://www.pochemu-kuda-zachem.club/`

## Диагноз (02.10.2026)

- Сайт не находится в Google даже по точному названию.
- Мобильный Googlebot (вертикальный экран) видел только заглушку «Пожалуйста, переверните устройство».
- В исходном HTML нет текста: пустой `<div id="root">`. Правила спрятаны в модалках и доступны только после входа.
- Сайт отвечает на двух адресах (`chgk-mu.vercel.app` и `www.pochemu-kuda-zachem.club`), canonical не указан.
- `robots.txt`, `sitemap.xml` и любые несуществующие адреса отдавали HTML игры с кодом 200.
- Нет description, Open Graph, микроразметки Schema.org.
- Фавикон весит 2,1 МБ.

## Этап 5. Внешние действия

**Сделано 02.10.2026:** деплой; Google Search Console (ресурс с префиксом URL, подтверждение файлом `google074025d19201d681.html`, sitemap, запрос индексирования главной и `/pravila/`); Яндекс Вебмастер (подтверждение файлом `yandex_fa184ebb1ecd5b86.html`, sitemap, переобход двух страниц); 301 с `chgk-mu.vercel.app` сделан через `vercel.json`. Файлы подтверждения не удалять.

Наблюдение: до правок главная уже была в индексе Google, но в сохранённой копии была только заглушка `rotate-device-prompt`.

Осталось:
1. **Задеплоить** изменения (push в `master`).
2. **Google Search Console** (search.google.com/search-console):
   - добавить ресурс-домен `pochemu-kuda-zachem.club` (подтверждение через DNS TXT-запись у регистратора);
   - отправить `https://www.pochemu-kuda-zachem.club/sitemap.xml`;
   - «Проверка URL» → главная и `/pravila/` → «Запросить индексирование»;
   - в той же проверке посмотреть скриншот, который видит Googlebot.
3. **Яндекс Вебмастер** (webmaster.yandex.ru): то же самое — подтвердить сайт, добавить sitemap, отправить страницы на переобход.
4. **Vercel → Settings → Domains**: убедиться, что `www.pochemu-kuda-zachem.club` — основной (Production) домен.
5. **Проверить превью:** вставить ссылку в Telegram/Discord. При старом превью — @WebpageBot в Telegram для сброса кэша.
6. **Rich Results Test** (search.google.com/test/rich-results): прогнать главную, убедиться, что JSON-LD читается без ошибок.
7. **Внешние ссылки** (без них новый домен ранжируется медленно):
   - профиль GitHub / README, если репозиторий станет публичным;
   - ЧГК-сообщества, Discord-каталоги серверов и игр, Pikabu / vc.ru / Habr (пост о создании игры), Telegram-каналы про квизы и настольные игры;
   - ссылка в описании своих соцсетей.
8. Через 1–2 недели проверить в Search Console отчёт «Страницы» — какие адреса проиндексированы и почему остальные нет.
