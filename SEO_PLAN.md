# План SEO-продвижения «Почему? Куда? Зачем?»

Основной домен: `https://www.pochemu-kuda-zachem.club/`

## Диагноз (02.10.2026)

- Сайт не находится в Google даже по точному названию.
- Мобильный Googlebot (вертикальный экран) видел только заглушку «Пожалуйста, переверните устройство».
- В исходном HTML нет текста: пустой `<div id="root">`. Правила спрятаны в модалках и доступны только после входа.
- Сайт отвечает на двух адресах (`chgk-mu.vercel.app` и `www.pochemu-kuda-zachem.club`), canonical не указан.
- `robots.txt`, `sitemap.xml` и любые несуществующие адреса отдавали HTML игры с кодом 200.
- Нет description, Open Graph, микроразметки Schema.org.
- Фавикон весит 2,1 МБ.
